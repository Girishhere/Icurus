**The Problem**

Modern AI coding assistants are static.

They generate code once — and stop.

❌ No execution
❌ No validation
❌ No correction
❌ No learning

---------------------------------------------------------------------

**The Solution**

Icurus is a self-improving AI agent that:

* Writes code
* Executes it
* Detects failures
* Fixes itself automatically

---------------------------------------------------------------------

End-to-End Pipeline
---------------------------------------------------------------------
Step-by-Step Flow

1️.The Scout
Scrapes live DSA problems using BrightData

2️.The Architect
Generates initial solution using Featherless AI

3️.The Sandbox
Runs code using Python subprocess
Captures errors and outputs

4️.The Critic
Analyzes failure logs

5️.The Optimizer
Improves code using feedback loop

-------------------------------------------------------------------------------------------

**Feedback Loop**

Problem → Generate → Execute → Fail → Fix → Repeat → Success

**Quick Start**

1. Clone Repo

```bash
git clone https://github.com/your-username/icurus.git
cd icurus
```

2. Create `.env`

```env
BRIGHTDATA_API_KEY=your_key
FEATHERLESS_API_KEY=your_key
```

3. Install

```bash
pip install -r requirements.txt
```

4. Run

```bash
python main.py
```
